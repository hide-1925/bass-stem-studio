# LICENSE の決定

**2026-09-29 owner の判断：付けない（Private のまま運用）。公開するときに改めて選ぶ。**

## 現状（F-04）

- `LICENSE` ファイルが無い。README にもライセンスの記述が無い
- ライセンスの無いリポジトリは、公開しても「閲覧はできるが、複製・改変・再配布の許諾は無い」扱いになる

## 同梱・依存しているもののライセンス

| もの | ライセンス | 扱い |
|---|---|---|
| Signalsmith Stretch（`web/js/vendor/`、同梱） | MIT | 著作権表示を `LICENSE-signalsmith-stretch.txt` で同梱済み |
| Demucs | MIT | pip で取得（同梱なし） |
| Basic Pitch | Apache-2.0 | pip で取得（同梱なし） |
| htdemucs_6s のモデル重み | Demucs のリポジトリのライセンスに従う | 初回実行時にダウンロード（同梱なし） |
| librosa / PyTorch / FastAPI ほか | ISC / BSD / MIT など | pip で取得（同梱なし） |

どのライセンスを選んでも、同梱物（MIT）との衝突は起きにくい。GPL を選ぶ場合も MIT の同梱物は取り込める。

## 選択肢

| | 商用 | 改変 | 再配布 | 改変版のソース公開義務 | 特許 | 向いている場合 |
|---|---|---|---|---|---|---|
| MIT | 可 | 可 | 可 | なし | 明示なし | 自由に使ってほしい。最も短い |
| Apache-2.0 | 可 | 可 | 可 | なし | 明示の許諾あり | 自由に使ってほしいが、特許の扱いも明確にしたい |
| GPL-3.0 | 可 | 可 | 可 | 派生物全体 | 明示の許諾あり | 派生物も必ずオープンにしてほしい |
| 何も付けない | 不可 | 不可 | 不可 | — | — | Private のまま、または見せるだけ |

## 決まったらやること

1. 選んだライセンスの全文を `LICENSE` に置く（著作権者の表記は owner が指定。実名を出したくなければ GitHub のハンドル `hide-1925` でよい）
2. README にライセンスの節を追加して `LICENSE` へリンクする
